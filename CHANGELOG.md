# Changelog

## 1.0.0 (2026-11-09)

First public release.

- One-click setup for Windows 10/11 (x64 and ARM): checks the PC, recommends a model, downloads with resume and checksum checks
- Chat interface in English and Persian (right to left), light and dark themes
- Chat history, search, pictures and text files, "Think" mode, custom instructions
- Model manager: recommended models, any model from the Ollama library
- Coding agent (OpenCode) in the browser or a terminal, with an optional right-click menu
- Portable: everything stays in one folder and runs from a copy without internet
- Engine: Ollama 0.40.15 · Coding agent: OpenCode 1.19.5
